# LifeWise 交接文档

## 项目目标

提供一个移动端生活助手，支持用户自定义 OpenAI-compatible 模型，并在聊天中使用文字、图片、语音、结构化场景卡片和导出能力。

## 当前阶段

Android 本地优先版 `1.1 (versionCode 2)` 已完成本轮移动端体验修复、完整构建和自动化验证。下一步是在 Android 真机逐项验证交互行为。

2026-10-15 追加：完成仓库瘦身与文档校准，跟踪体积从 91.5 MB 降到约 2.9 MB，并把「本地优先 / 服务端」两套形态的区别写进 README 与 AGENTS.md。

## 架构前提（2026-10-15 补充）

仓库内并存两套形态，改动前先确认改的是哪一套：

- **本地优先（当前主线，APK）**：`frontend/src/local/` 负责 AI 调用与数据（`localStorage`）。
- **服务端（历史形态，Web 部署）**：`backend/` + `deploy/`，仅 Web 部署使用。

`frontend/src/api/index.js` 已完全本地化，不再请求后端；因此本地模式的问题基本不在后端。

## 关键决策

- APK 采用本地优先模式，AI URL、API Key 和模型由用户在“我的”页面配置，不依赖 LifeWise 服务端。
- APK 流式请求使用 Android 原生插件，因为 CapacitorHttp 会缓冲完整响应。
- 图片发送前最大边长压缩到 1600px，避免手机原图转 Base64 后造成请求体过大。
- 导出统一写入 Android 公共文档目录下的 `LifeWise` 子目录，并通过系统分享面板提供后续保存或发送。
- 不在代码、文档或构建产物说明中记录真实 API Key。
- 构建产物、运行时数据库与用户上传一律不进 git：`deploy/` 下的前端包和 JAR 由 CI 每次 push 重新生成，提交副本只会变成过期 bundle。该清单同时维护在 `.gitignore` 与 `AGENTS.md`。
