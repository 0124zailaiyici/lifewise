# LifeWise 交接文档

## 项目目标

提供一个移动端生活助手，支持用户自定义 OpenAI-compatible 模型，并在聊天中使用文字、图片、语音、结构化场景卡片和导出能力。

## 当前阶段

Android 本地优先版 `1.1 (versionCode 2)` 已完成本轮移动端体验修复、完整构建和自动化验证。下一步是在 Android 真机逐项验证交互行为。

## 本轮已完成

- [x] AI 文本回答支持 SSE 流式显示；模型不支持流式时自动回退普通响应。
- [x] APK 增加原生 AI 流式插件，绕过 CapacitorHttp 对流响应的缓冲。
- [x] 聊天页显示当前实际配置模型，不再硬编码“千问 Qwen / 小米 MiMo”。

## 关键实现路径

- 前端聊天：`frontend/src/views/Chat.vue`
- 本地 AI 客户端：`frontend/src/local/aiClient.js`
- 场景提示：`frontend/src/local/scenePrompts.js`
- API 封装：`frontend/src/api/index.js`
- Android 返回处理：`frontend/src/main.js`
- 原生流式插件：`frontend/android/app/src/main/java/com/lifewise/app/NativeAiStreamPlugin.java`
- 原生语音插件：`frontend/android/app/src/main/java/com/lifewise/app/NativeSpeechPlugin.java`
- Android 权限：`frontend/android/app/src/main/AndroidManifest.xml`
- APK 构建脚本：`build-apk.bat`
- APK 主产物：`release/LifeWise-local-debug.apk`
- APK 版本化副本：`release/LifeWise-1.1-local-debug.apk`

## 关键决策

- APK 采用本地优先模式，AI URL、API Key 和模型由用户在“我的”页面配置，不依赖 LifeWise 服务端。
- APK 流式请求使用 Android 原生插件，因为 CapacitorHttp 会缓冲完整响应。
- 图片发送前最大边长压缩到 1600px，避免手机原图转 Base64 后造成请求体过大。
- 导出统一写入 Android 公共文档目录下的 `LifeWise` 子目录，并通过系统分享面板提供后续保存或发送。
- 不在代码、文档或构建产物说明中记录真实 API Key。
